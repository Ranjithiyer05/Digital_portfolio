# Ranjith Iyer · Portfolio

Personal portfolio website: projects, skills, certifications, resume download and a contact form.

Live site (after enabling GitHub Pages): https://ranjithiyer05.github.io/Digital_portfolio/

## Files
- `index.html` — the whole site (HTML, CSS and JS in one file, no build step)
- `Ranjith_Iyer_CV.pdf` — the resume behind every "Download resume" button

## Updating
- **New project:** in `index.html`, search for `<article class="proj`, copy one block and edit it.
- **New skill:** search for `var S=[` and add a line like `['Languages','Go'],`.
- **New resume:** replace `Ranjith_Iyer_CV.pdf`, keeping the same file name.

The contact form sends through [FormSubmit](https://formsubmit.co). The first message triggers a one-time activation email to the inbox; click "Activate" once.
