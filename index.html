Web archive and change detection

Strata

A web memory tool that crawls websites and stores a new page version only when the main readable text actually changes.

  • Crawler that respects robots.txt, reads gzipped sitemaps, walks links breadth-first and handles canonical URLs and redirects.
  • SHA-256 fingerprints of the readable text, so navigation, footers and timestamps never register as false changes.
  • A time machine with version timelines, inline and side-by-side word-level diffs, and replay of archived pages.
  • Change feed, SQLite FTS5 full-text search over the whole history, and a link doctor that flags broken links and offers preserved copies.
  • Zero dependencies, live crawl progress over Server-Sent Events, scheduled re-crawls, crash-safe resume, ZIP export and custom SVG charts.

AI complaint management

AI-Based Grievance Redressal System

A platform where students and staff raise complaints and an LLM reads each one, classifies it, judges its urgency and spots duplicates.
